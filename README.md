# Landing para negocio local

Plantilla de landing page en HTML, CSS y JavaScript puro para pequeños negocios locales (peluquerías, barberías, bares, talleres…). Pensada para personalizarse rápido por cliente: colores, textos, fotos y datos de contacto.

## Estado

En definición. La especificación se escribe antes de programar (`docs/SPEC.md`).

## Stack

- HTML5, CSS3 y JavaScript sin frameworks ni build
- Despliegue como sitio estático
